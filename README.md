# Real-time Object Detector (YOLOv8 + OpenCV)

Небольшой проект, распознающий объекты в реальном времени через веб-камеру.

## Как это работает

Скрипт берёт видеопоток с веб-камеры, прогоняет каждый кадр через предобученную
модель YOLOv8 и рисует рамки вокруг найденных объектов (люди, стулья, телефоны,
чашки и ещё ~80 классов из датасета COCO).

## Установка

```bash
pip install opencv-python ultralytics
```

## Запуск

```bash
python object_detector.py
```

Нажми `q` в открывшемся окне, чтобы завершить работу.

## Технологии

Python, OpenCV, Ultralytics YOLOv8
